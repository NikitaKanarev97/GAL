# GAL — логотип

Исходник клиента: `_source/client-logo-original.jpg` (640×640). Бриф и JSON-промпты: `logo-brief.md` в корне.

## 3 варианта на выбор (2026-09-16)

Концепты — Krea `openai/gpt-image-2.5-flare`, логотип клиента референсом, прозрачный фон. Вектор — `scripts/vectorize-logo.py`: ровно 3 цвета `#0A0A0A` · `#FF5A00` · `#F5EEDD`, без эмблемы и букв BMW, без машин и QR.

| Вариант | SVG | Идея | Где силён |
|---|---|---|---|
| v1 «Эволюция» | `svg/gal-logo-v1-evolution.svg` | их логотип, вычищенный: арка-наклейка, доберман, спортивные буквы GAL | мерч, стикеры, аватарка — клиент узнает свой знак |
| v2 «Сайт» | `svg/gal-logo-v2-site.svg` | жетон-шестигранник, геометричный доберман, широкий курсив GAL с оранжевой A без перемычки — как заголовки сайта и знак из макета | одна система с сайтом, OG, футер |
| v3 «Шапка» | `svg/gal-logo-v3-header.svg`, `svg/gal-logo-v3-header-on-light.svg` | горизонтально: голова добермана + GAL | шапка сайта; голова отдельно — фавикон |

Превью на тёмном и светлом фоне: `_concepts/svg-preview-sheet.jpg`. Сырые концепты: `_concepts/v*.png`.

Варианты не исключают друг друга: v1 или v2 — эмблема, v3 — горизонтальный знак для шапки.

**Не сделано до выбора:** фавиконы (16/32/48 ico, svg, 180, 192, 512), OG 1200×630, моно-версии.
**Ограничение:** SVG получен трассировкой. Для печати крупного формата (вывеска) выбранный вариант стоит перерисовать вручную — узлов много, у v1 файл 364 КБ.
