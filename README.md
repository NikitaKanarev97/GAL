# GAL — запчасти BMW под заказ

Лендинг GAL: б/у и новые запчасти BMW под заказ, сервис и Gal custom. Заявка уходит в Telegram с готовым текстом: какой раздел, какой кузов.

Статус: сайт свёрстан, данные пока лежат в коде (`src/data/seed`). Дальше по плану — админка Directus, чтобы тексты, позиции и фото правились без программиста, и запуск на домене.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер с горячей перезагрузкой |
| `npm run build` | продакшен-сборка |
| `npm run start` | запуск собранного сайта |
| `npm run typecheck` | проверка типов TypeScript |

## Страницы

| Адрес | Что там |
|---|---|
| `/` | главная — все блоки сверху вниз |
| `/parts/[раздел]` | раздел запчастей (двигатель, ходовая, свет…); с главной открывается попапом |
| `/privacy` | политика конфиденциальности |
| `/showcase` | служебная витрина цветов, шрифтов и кнопок |

## Где что лежит

| Папка | Содержимое |
|---|---|
| `src/app/` | страницы и маршруты (Next.js App Router) |
| `src/components/blocks/` | блоки главной: Hero, Parts, Service, Custom, FAQ, Contacts… |
| `src/components/contact/` | выбор кузова и темы, переход в Telegram |
| `src/components/motion/` | прелоадер и анимации при скролле (GSAP, Lenis) |
| `src/data/` | данные сайта; после подключения Directus будут приходить из админки |
| `src/styles/tokens/` | цвета, шрифты, сетка |
| `assets/` | фото и логотип, которые использует сайт |
| `assets/logo/` | три варианта логотипа на выбор, описание — в `assets/logo/README.md` |

## Стек

Next.js 16, React 19, TypeScript, CSS Modules, GSAP, Lenis.
